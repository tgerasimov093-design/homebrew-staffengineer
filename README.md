# StaffEngineer для macOS

Приложение связывает личный Codex или Claude Code с интервьюером на доске StaffEngineer. Для работы нужен Mac с Homebrew и установленный агент, в котором вы вошли в свой аккаунт.

    brew install tgerasimov093-design/staffengineer/interview && staffengineer-register

Откройте [доску](https://staffengineer.ru/systemdesign/mcp), нажмите «Мой ИИ» и выберите агента. Если браузер запросит разрешение открыть приложение или подключиться к устройству, подтвердите. После подключения задавайте вопросы на доске. Терминал можно закрыть.

Значок с двумя облачками в строке меню позволяет отключиться и выйти. Чтобы снова подключить агента, нажмите кнопку на доске. Для удаления выполните:

    brew uninstall tgerasimov093-design/staffengineer/interview

## Как работает подключение

Homebrew собирает приложение из исходников и регистрирует ссылку staffengineer-interview в macOS. Приложение принимает запросы с доски через локальный порт 38473. Одноразовый код передаётся после проверки случайного значения из ссылки. Сервер обменивает его на ключ доски. Коннектор хранит ключ в памяти и вызывает выбранный CLI для ответов в чате. Расход учитывается в аккаунте пользователя. Поддерживаются staffengineer.ru и локальная доска на localhost:5173.
